Hybrid Movie Recommender

What this app does

  • Hybrid = Content (TF-IDF) + KNN collaborative + RandomForestClassifier.
  • Top-N recommendations with why (confidence + similar movies).
  • Session feedback (👍/👎) + star ratings to nudge rankings without retraining.

Rate a few movies (new user)

Rate some movies to give the system an idea of your taste. Ratings 4–5 are treated as likes, 1–2 as dislikes in this session.

Feedback is stored in this browser session and used on "Get Recommendations".

Get Recommendations

Use any valid UserID from the MovieLens dataset.
